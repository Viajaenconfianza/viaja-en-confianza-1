2. Datos personales que podemos recabar

Según el servicio solicitado, podremos recabar:

  • Identificación: nombre completo, fecha de nacimiento, nacionalidad y datos de identificación o pasaporte cuando sean necesarios para una reservación.
  • Contacto: teléfono, WhatsApp, correo electrónico y domicilio cuando sea necesario.
  • Viaje: destinos, fechas, número de viajeros, edades de menores cuando corresponda, preferencias y datos necesarios para gestionar reservaciones.
  • Operaciones y pagos: servicios cotizados, referencias de reservación, comprobantes de transferencia y datos limitados de transacciones proporcionados por las plataformas de pago.
  • Facturación: RFC, nombre o denominación fiscal, código postal fiscal, régimen fiscal y uso del comprobante, cuando el cliente solicite factura.

Los pagos con tarjeta podrán procesarse a través de plataformas habilitadas. No solicitaremos por mensajes contraseñas bancarias ni códigos de autenticación.

3. Datos personales sensibles

No tenemos como finalidad recabar rutinariamente datos personales sensibles. En casos concretos, el cliente podría proporcionar información sobre salud, discapacidad, movilidad o necesidades especiales para gestionar un servicio. Si esa información constituye legalmente un dato sensible, se tratará conforme a los requisitos aplicables y con el consentimiento que corresponda.

Recomendamos no enviar información médica detallada si no resulta necesaria para el servicio solicitado.

4. Finalidades primarias

Utilizaremos los datos personales para:

  1. Atender consultas recibidas por llamadas, WhatsApp, correo electrónico o sitio web.
  2. Elaborar y dar seguimiento a cotizaciones.
  3. Consultar disponibilidad y tarifas con proveedores.
  4. Gestionar reservaciones de hoteles, paquetes, tours, excursiones, vuelos y servicios relacionados.
  5. Solicitar o entregar confirmaciones, boletos, vouchers y documentación.
  6. Verificar pagos y dar seguimiento a las operaciones.
  7. Gestionar cambios, cancelaciones, reembolsos y reclamaciones.
  8. Cumplir obligaciones contractuales, fiscales, contables y legales.
  9. Contactar al cliente sobre su solicitud, reservación o viaje.
  10. Atender solicitudes relacionadas con sus datos personales.

Si no se proporcionan los datos indispensables para una operación, podría no ser posible cotizar, confirmar o prestar el servicio solicitado.

5. Finalidades secundarias

Cuando sea legalmente procedente, podremos utilizar los datos de contacto para enviar información sobre destinos, servicios, promociones y novedades, así como para solicitar comentarios sobre la experiencia de atención.

El titular puede solicitar que sus datos no se utilicen para estas finalidades promocionales escribiendo a ventas@viajaenconfianza.com. La oposición a promociones no impedirá las comunicaciones necesarias para gestionar servicios contratados.

6. Comunicación y transferencia de datos

Para gestionar el servicio solicitado, podremos comunicar los datos estrictamente necesarios a hoteles, aerolíneas, transportistas, operadores turísticos, parques, mayoristas, plataformas de reservación, plataformas de pago, entidades financieras y proveedores tecnológicos o administrativos.

También podrán comunicarse datos a autoridades competentes cuando exista una obligación legal. Algunos proveedores pueden encontrarse fuera de México. Cuando existan transferencias internacionales, se atenderán los requisitos legales aplicables y se informará al titular cuando corresponda.

Viaja en Confianza no vende datos personales de clientes como actividad comercial.

7. Llamadas, WhatsApp y correo electrónico

Podremos utilizar los datos de contacto para atender consultas, preparar cotizaciones, dar seguimiento a solicitudes, confirmar pagos y reservaciones, informar sobre incidencias y gestionar solicitudes posteriores al viaje.

Las llamadas no se grabarán de manera ordinaria. Si se implementara un sistema de grabación, se informará al titular cuando corresponda y se atenderán los requisitos legales aplicables.

8. Cookies y tecnologías similares

El sitio puede utilizar cookies o tecnologías similares para funciones técnicas, seguridad, preferencias o análisis, según las herramientas que estén activas. El usuario puede gestionar las cookies desde la configuración de su navegador. Algunas funciones podrían verse afectadas si se deshabilitan las cookies necesarias.

Si se incorporan herramientas de publicidad o seguimiento de terceros, se actualizará este aviso cuando corresponda.

9. Seguridad y conservación

Adoptaremos medidas administrativas, técnicas y físicas razonables para proteger los datos contra pérdida, alteración, uso indebido, acceso no autorizado o divulgación.

Los datos se conservarán durante el tiempo necesario para cumplir las finalidades descritas y las obligaciones legales, fiscales o contractuales aplicables. Después, se eliminarán, bloquearán o anonimizarán cuando corresponda.

10. Derechos ARCO

El titular podrá ejercer los derechos de acceso, rectificación, cancelación y oposición en los términos de la legislación aplicable.

Para iniciar una solicitud, escriba a ventas@viajaenconfianza.com con el asunto “Solicitud de derechos ARCO – Datos personales”.

La solicitud deberá incluir el nombre del titular, un medio para recibir respuesta, los documentos necesarios para acreditar identidad y representación cuando corresponda, una descripción de los datos y el derecho que desea ejercer, así como cualquier información que ayude a localizar los datos.

Las solicitudes se atenderán dentro de los plazos y conforme al procedimiento previstos por la legislación aplicable. El ejercicio de los derechos puede estar sujeto a excepciones legales, por ejemplo, cuando deban conservarse datos por obligaciones vigentes.

11. Revocación y limitación del uso

Cuando el tratamiento se base en el consentimiento, el titular podrá solicitar su revocación mediante el correo indicado. La revocación no tendrá efectos retroactivos ni impedirá los tratamientos que deban continuar por obligación legal u otra base jurídica válida.

También podrá solicitar la limitación de sus datos para finalidades promocionales cuando corresponda.

12. Datos de menores de edad

Cuando se necesiten datos de menores para una reservación, deberán proporcionarse por su madre, padre, tutor o persona autorizada, según corresponda. Se tratarán únicamente para las finalidades necesarias del servicio y con las medidas de protección aplicables.
